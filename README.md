# Inventory Management System
A full-stack CRUD app to manage products and stock with Admin/User roles.

## Features
- JWT login/register
- Admin: add, update, delete products, update stock
- User: view inventory

## Tech Stack
React + Vite, React Router, Axios | Node.js, Express, MongoDB Atlas, Mongoose, JWT
